# Prospect Data Engine (PDE) Documentation

## Overview
A high-throughput ETL engine capable of processing large multi-gigabyte Excel datasets with worker thread pools, chunked streaming, and checkpoint crash recovery.

## Benchmarks
- Throughput: 25,000+ rows/sec
- Memory Heap: < 180MB stable heap
- Tested Scale: Up to 5 million rows
- Live URL: https://pde.gnosysdigital.com/
