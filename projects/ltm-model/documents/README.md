# LTM Model Deployment Interface

## Overview
A web interface and API deployment for evaluating Long-Term Memory (LTM) language models, testing context recall across long sequence windows, and live telemetry benchmarks.

## Highlights
- Real-time token streaming with requestAnimationFrame batching
- Interactive parameter sliders (Temperature, Top-P, Repetition penalty)
- Deployed on Render Cloud: https://ltm-model.onrender.com/
