# PaintEye Documentation

## Overview
A modern color analytics and architectural paint visualizer powered by Next.js App Router, Prisma ORM, and PostgreSQL.

## Features
- In-browser CIE-Lab color distance matching
- Dynamic ambient lighting simulation (2700K to 6500K)
- Sub-45ms database query response across 15,000+ formulations
- Live URL: https://painteye.com/
